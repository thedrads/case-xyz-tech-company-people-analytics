# Política de segurança

## Relato de vulnerabilidades

Não publique informações sensíveis em issues públicas.

Para relatar uma vulnerabilidade ou exposição acidental de dados, entre em contato com o mantenedor pelo perfil [@thedrads](https://github.com/thedrads) e descreva:

- natureza do problema;
- arquivo ou componente afetado;
- passos para reprodução;
- impacto potencial;
- sugestão de correção, quando disponível.

## Escopo

Este é um projeto acadêmico de análise de dados. Ainda assim, contribuições não devem incluir:

- credenciais;
- tokens de acesso;
- chaves de API;
- dados pessoais ou corporativos reais;
- arquivos `.env`;
- informações confidenciais de candidatos ou colaboradores.

## Dependências

As dependências devem ser mantidas em `requirements.txt`. Alterações de versão devem ser testadas por meio da execução integral do notebook.
